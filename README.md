# nodus

## Run from the console

Use the executable launcher in the project root:

```bash
/path/to/Nodus/nodus init
```

The launcher compiles the project into `target/classes` when sources change, then
runs the CLI against the current terminal directory.

Example:

```bash
mkdir /tmp/nodus-demo
cd /tmp/nodus-demo
/Users/PersonalFileSystem/01_PROJECTS/00_NODUS/Nodus/nodus init
```
